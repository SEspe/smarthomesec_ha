# Licensing

## Status

This repository is released under the [MIT License](../LICENSE). The changes in this fork are MIT.

Why MIT and not CC0: HACS's license check requires an OSI-approved license. CC0 is not OSI-approved, and a strict HACS validation run on this repo failed on it (PR #42, `HACS` job, `Validation license`). MIT passes that check. Upstream's author's public-domain statement (below) is unaffected: public-domain code can be used under any license.

## Basis

Upstream is [koying/smarthomesec_ha](https://github.com/koying/smarthomesec_ha), which has no LICENSE file. Its author, Chris Browet (koying), was asked whether the fork could be used and redistributed in [koying/smarthomesec_ha#3](https://github.com/koying/smarthomesec_ha/issues/3).

His reply, verbatim, posted 2026-11-07 08:55 UTC:

> Happy to have been of help.
> I'm fine with the fork, consider this repo public domain.
>
> Thanks

Upstream has not added a LICENSE file. We have not asked him to add one.
